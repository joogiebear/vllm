# OVERCLOCK

A browser idle game about keeping an AI inference server alive. You are the
scheduler: tokens are generated by inference work (pipelines, gamers, labs,
clusters, and finally the model itself), and you buy generators, upgrades,
and weight upgrades that make the server run faster. When the server has
earned enough total work, you can prestige — retire the model for a new
generation — and trade the reset for weights that permanently speed up the
next run.

**Rush is a bonus mode**: the original arcade (drag requests onto two GPUs,
keep the silicon from cooking) lives at `rush.html`. It is a one-shot arcade
run; the score you finish with is paid out as tokens in the idle game, with a
cooldown between runs.

The Shop tab in `index.html` is placeholders only: nothing is for sale, no
prices are shown, and no payment code, links or network requests exist.

## How to play

- **Idle (index.html):** buy generators and upgrades with tokens; buy weight
  upgrades with weights. Click the click button for a manual burst. Overclock
  doubles output but adds heat; at heat 100 the server throttles. Prestige
  when you have weights available — it resets the run but keeps weights,
  weight upgrades, and total progress.
- **Rush (rush.html):** mouse / touch — drag a queue card onto a slot, or tap
  a card and then tap a slot; tap a filled slot to evict. Keys — `1`-`9` (and
  `0` for card 10) select a queue card; `Q W E R` and `A S D F` assign the
  selected card to slots on GPU 1 and GPU 2; `Z` and `X` boost the GPUs;
  `P` pauses, `M` mutes. On the upgrade screen, `1 2 3` pick an upgrade.
  A request runs 1.5× faster on a matching prefix, but a cache miss stalls the
  slot for 1 second. Finishing requests raises your multiplier (up to 3×); any
  timeout or dropped arrival resets it.

## Running it locally

There is no build step. Serve the repo from any static file server:

```
python3 -m http.server
```

Then open http://localhost:8000 (or the port it prints) for the idle game,
or http://localhost:8000/rush.html for the arcade. The game works from any
static host, e.g. GitHub Pages.

## Running the tests

```
node --test test/sim.test.js test/idle.test.js
```

The rule tests are pure Node built-ins; `src/sim.js` and `src/idle/core.js`
are deterministic (no DOM, no `Date`, no `Math.random`).

Headless balance checks are available at `node tools/balance.js` (arcade: two
bots, 200 seeds each) and `node tools/idle-balance.js` (idle pacing bot).
